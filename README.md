## 🚀 Project Overview

The **Online Class Management System** is a cutting-edge **WhatsApp Automation Bot** designed to streamline and automate essential tasks for educational institutions and online tutors. Built with a modern tech aesthetic and robust backend, this system ensures students receive timely notifications and class materials directly via WhatsApp.

### Key Features:
-   🔔 **Automated Notifications:** Sends reminders for upcoming classes (e.g., "Your Math class starts in 10 minutes!").
-   📅 **Schedule Management:** Fetches and displays daily/weekly class schedules.
-   📚 **Assignment Uploads:** Automatically confirms and notifies when students submit assignments.
-   💬 **Interactive Messaging:** Handles common student inquiries with predefined automated responses.
-   💾 **Scalable Architecture:** Built for high performance and easy integration with existing systems.
